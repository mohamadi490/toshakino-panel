# مستندات ماژول‌ها

برای هر ماژول یک فایل با همین قالب:

1. **هدف و دامنه** - چه چیزی هست و چه چیزی نیست.
2. **قرارداد مصرف‌شده** - `operationId` ها، پارامترها، schemaهای مهم.
3. **مجوزها** - کدهای مورد استفاده و رفتار UI بدون مجوز.
4. **صفحه‌ها و رفتار** - مسیرها، حالت‌ها، قواعد اعتبارسنجی.
5. **خطاها** - `code` های مهم و پیام نمایشی.
6. **محدودیت‌ها و سؤال‌های باز** - لینک به `docs/open-questions.md`.
7. **تست‌ها** - چه چیزی پوشش داده شده.

| ماژول | فایل | وضعیت |
|---|---|---|
| هسته (API، Auth، خطا، پول) | `core.md` | در PR هم‌ترازی هسته |
| کاربران و نقش‌ها | `access-control.md` | برنامه‌ریزی‌شده (B1) |
| دسته‌بندی/برند/ویژگی | `catalog-taxonomy.md` | برنامه‌ریزی‌شده (B2) |
| رسانه | `media.md` | برنامه‌ریزی‌شده (B3) |
| محصولات | `products.md` | برنامه‌ریزی‌شده (B4) |
| سفارش‌ها | `orders.md` | برنامه‌ریزی‌شده (B5) |
| داشبورد | `dashboard.md` | برنامه‌ریزی‌شده (B6) |
| موجودی | `inventory.md` | برنامه‌ریزی‌شده (B7) |
| تنظیمات فروشگاه | `store-settings.md` | برنامه‌ریزی‌شده (B8) |
